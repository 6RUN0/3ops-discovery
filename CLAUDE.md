# X-Alloy Discovery

Specification of a labels-driven telemetry discovery contract for
Grafana Alloy (`docs/manifest.ru.md`, Russian-only) plus the reference
Alloy configuration (`alloy/*.alloy`) and the quality gates that bind
them together.

## Commands

- `uv run nox` — default gates: lint + docs_lint + alloy_check + tests.
  Honestly requires Docker (alloy_check) and network (lychee); the
  fully offline set is `uv run nox -s lint tests`.
- `uv run nox -s lint` — pre-commit hooks on all files.
- `uv run nox -s docs_lint` — rumdl + typos + lychee (system binaries).
- `uv run nox -s alloy_check` — `alloy fmt -t` + `validate` for every
  config combination, inside the pinned Docker image.
- `uv run nox -s tests` — static manifest-vs-config gates + mini-app
  units (no Docker).
- `uv run nox -s e2e` — docker compose delivery checks (opt-in, takes
  minutes). Subset: `uv run nox -s e2e -- tests/e2e/test_logs_delivery.py`.
- `uv run nox -s preflight` — everything.

## Architecture

- `docs/manifest.ru.md` — the contract; normative tables/blocks are
  extracted by ANCHORS (section number + position) in
  `tests/static/manifest_doc.py`. Restructuring the manifest breaks
  the gates loudly; deliberate counterexamples in the text are never
  extracted.
- `alloy/*.alloy` — reference config; one directory = one merged
  component graph, unique component names, no overrides possible.
- `tests/static/` — manifest vs config consistency; allowed gaps live
  in `asymmetries.py` as one explicit table.
- `tests/e2e/stack/` — compose stack: Alloy reaches the Docker API
  only through docker-socket-proxy (GET-only, internal network);
  alloy/prometheus/loki monitor themselves through the contract
  labels (dogfooding).
- `tools/materialize.py` — builds the config dir (base + optional)
  for both alloy_check and the e2e mount.

## Hard rules

- The Alloy image tag is pinned BY THE MANIFEST (section 14, currently
  v1.17.1); `noxfile.ALLOY_IMAGE` must match — a static test enforces
  it. `foreach` is experimental: always `--stability.level=experimental`.
- Contract values (scrape intervals, label names, defaults) are never
  changed to make a test pass; e2e accelerates only
  `XAD_DOCKER_REFRESH_INTERVAL`.
- No secrets in git, not even fakes: `*.dsn` etc. are generated by
  fixtures into gitignored temp dirs.
- Versions of external artifacts (packages, images, hook revs) are
  pinned from live sources, never from memory.
- Discovery labels in compose files use the LIST form
  (`- "x-alloy-discovery.enabled=true"`): compose treats an `x-`
  prefixed key in a `labels:` mapping as an extension and drops it.
- The manifest is Russian-only by design; code, comments, commits and
  shipped markdown are English.
- Conventional Commits; no AI-attribution trailers.
